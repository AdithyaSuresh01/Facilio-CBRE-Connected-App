Place the image assets for the Facilio package in this folder (SVG only):

- `facilio-logo.svg` (used in header and footer)
- `hero-illustration.svg` (used in hero banner)

You can replace these with your final design-exported SVG files before uploading to Facilio.

For Connected Apps integrations using renamed paths, mirrored assets are also available in:

- `app/images/HelpGuides/facilio-logo.svg`
- `app/images/HelpGuides/hero-illustration.svg`
